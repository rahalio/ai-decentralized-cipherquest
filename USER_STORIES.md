# Cipherquest — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Competition organiser

- As an organiser, I want to publish a weekly sealed dataset with expiry, so that signal does not leak indefinitely.
- As an organiser, I want automatic ranking and top-N payout drafts, so that settlement is not a spreadsheet ritual.
- As an organiser, I want originality bonuses gated on a review ruling, so that copycat submissions are not overpaid.

### Data scientist participant

- As a data scientist, I want my model artefact to stay encrypted as my IP, so that winning does not mean giving away the weights.
- As a data scientist, I want to see the scoring definition and payout table before I invest compute, so that incentives are clear.
- As a data scientist, I want to challenge a score within a time box without receiving the holdout in cleartext, so that fairness does not equal leakage.

### Data steward / compliance

- As a data steward, I want provenance and ethical-sourcing tags on each release, so that “ethically sourced data” is evidenced.
- As a compliance officer, I want to halt a competition lacking lawful basis, so that tournaments cannot outrun policy.

### Payout operations

- As a payout operator, I want a dual-readable statement of ranks, originality rulings, and amounts, so that finance can close the week.
- As a payout operator, I want failed payouts to retry without reopening scoring, so that rail failures do not corrupt the leaderboard.

### Platform administrator

- As a platform admin, I want optional reverse-auction hooks for supply-chain organisers, so that the deck’s ai-in-blockchain use case can attach without rewriting the competition core.
- As a platform admin, I want expiry certificates for sealed datasets, so that auditors can verify time-bound access.
